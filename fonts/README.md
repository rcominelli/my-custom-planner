# Fonts

All fonts here are free to use and redistribute. They replace the Microsoft fonts used in the
2025-2026 manual templates.

| Font | Replaces | License |
|------|----------|---------|
| TeX Gyre Schola | Century Schoolbook (same character widths) | GUST Font License (`GUST-FONT-LICENSE.txt`) |
| TeX Gyre Adventor | Century Gothic (similar geometric sans) | GUST Font License (`GUST-FONT-LICENSE.txt`) |
| Carlito | Calibri (same character widths) | SIL Open Font License (`OFL-Carlito.txt`) |
| Caveat | Brush Script MT (handwritten pre-filled habits) | SIL Open Font License (`OFL-Caveat.txt`) |

The generator loads these fonts automatically on Linux and macOS. On Windows, install them
(right-click > Install) before opening the templates in Inkscape.
